The schematic and the firmware used to disagree

Earlier in this project, wattplot.yaml was compiled from an older C3-era pinout, while the schematic had moved on. v3 brings the firmware into line with the schematic. v3.1 removes the limit switches entirely and uses motor-current-spike detection via IPROPI for endstops.

Why "compat" entries remain: the state machine in wattplot.yaml still references id(hb_en_sw), id(solenoid_in2_out), and id(status_led) in scripts. v3 keeps these IDs in the firmware but reassigned to schematic "free" pins. Their actions have no physical effect (the board doesn't wire them), but the script.execute calls keep working without rewriting the control law.
